# Data folder

Raw fMRI, atlas, transcript, audio, and intermediate model outputs are not
included in this repository. Place local data here or point the notebooks to
your own data locations by replacing the `YOUR_*` placeholders.

Expected external inputs include:

- preprocessed fMRI data for all participants
- Schaefer 2018 400-parcel 17-network atlas NIfTI
- Schaefer parcel label text file
- story transcript and word onset/offset alignment
- optional audio file for acoustic-feature extensions
